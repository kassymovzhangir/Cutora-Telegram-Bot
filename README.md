# ✂️ Cutora — Telegram-бот для парикмахерской

## О проекте
Cutora — Telegram-бот для удобной записи клиентов в парикмахерскую. Он помогает выбрать мастера, посмотреть услуги и цены, записаться на удобное время.

**Telegram-бот:** https://t.me/CutoraSalon_bot

## Основные функции
- ✂️ Просмотр услуг и цен
- 👤 Выбор мастера: Арман, Айгерим, Данияр
- 📅 Запись на выбранное время
- 📋 Просмотр активной записи
- 🔄 Перенос записи на другое время
- ❌ Отмена записи
- 🏠 Возврат в главное меню

## Использованные технологии
- Python — программирование Telegram-бота
- pyTelegramBotAPI — взаимодействие с Telegram
- Supabase — база данных для записей в Python-версии
- Railway — развёртывание Python-версии
- Botmother — визуальное создание сценариев бота
- GitHub — хранение исходного кода

## Цель проекта
Упростить процесс записи клиентов, уменьшить количество ручных обращений к администратору и сделать выбор мастера и времени более удобным.
